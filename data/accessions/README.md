# NCBI accession metadata

`NCBI_SRA_metadata_190.tsv` contains the accession metadata for all 190 formal
biological libraries included in this study. Each library is represented once
and maps uniquely to one BioSample accession and one SRA run accession.

The metadata and `../manifests/sample_SAMN_SRR_crosswalk.tsv` were validated
for unique library names, BioSample accessions, SRA run
accessions, matching filenames, BioProject `PRJNA1513996`, and SRA study
`SRP727697`. Public accessibility without login was confirmed on 2026-10-02;
the BioProject lists 190 SRA experiments.
